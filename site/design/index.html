Design

UX, architecture critique, creative strategy, and poster/image generation — routed to the right agent and model.

Capabilities

  • Flow routes to analyst, architect, UX designer, and CIS creative skills
  • Auto Router picks design-capable models locally (e.g. Llama 3.1 8B) or on Rodium (Claude / Gemini mid–strong tiers)
  • Image / affiche prompts use quality-first cloud image models; CLI asks where to save the PNG
  • Project memory stores design decisions and preferences
  • RAG can ground answers in your design docs and assets
Quick start
akomagni run cli --project ./my-app
# Try: "wireframe the onboarding flow"
# Try: "brainstorm a mobile budget app UX"
# Try: "génère une affiche pour Akomagni"
akomagni memory add "Prefer clear hierarchy, high contrast" --title "Design prefs"
