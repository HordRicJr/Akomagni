Design

UX, architecture, and creative workflows with domain-aware models.

Capabilities

  • Route design questions to analyst, architect, and UX designer agents
  • Domain router selects llama-3.1-8b for design tasks by default
  • Project memory stores design decisions and stack preferences
  • RAG ingests design docs for grounded answers
Quick start
akomagni router classify "wireframe the onboarding flow"
akomagni flow route "brainstorm a mobile budget app UX"
akomagni memory add "Prefer card-based layouts" --title "Design prefs"
