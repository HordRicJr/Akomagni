Write

PRDs, docs, posts, and research — with project RAG and memory so context does not reset every chat.

Capabilities

  • Interactive CLI with Flow framing and local or cloud inference
  • Writing / storytelling / product skills via BMAD and CIS suites
  • RAG over markdown and project files for grounded answers
  • Auto-capture learnings into an approval queue before they hit memory
  • CLI UI English by default — akomagni config language fr for French
Quick start
akomagni run cli --project ./my-app
akomagni rag ingest docs/ --recursive
akomagni rag query "how does memory promotion work?"
akomagni memory pending
