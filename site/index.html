Akomagni

A new way to work with AI

Open-source hybrid workstation. Models, 17 BMAD agents, and a full skill kernel on install — turn a goal into a real process, local, cloud, or both.

Get started GitHub
Terminal 
curl -fsSL https://hordricjr.github.io/Akomagni/install/linux | bash
PowerShell 
irm https://hordricjr.github.io/Akomagni/install/windows | iex

Then akomagni connect · akomagni skill list · akomagni run cli --project ./app

What you get

Not only chat answers — competencies, specialized agents, and workflows that finish the job.

Skills

~110 BMAD / CIS / GDS methods for build, design, research, and writing. Installed with the product — no skill link or path setup.

Tools →

17 specialized agents

BMAD roles for product, architecture, UX, development, testing, and creative work.

Flow →

Akomagni Flow

Describe a goal in plain language. Flow routes agent + skill + workflow for you.

How it works →

Auto Router + model picker

Fits the model to the task on Rodium (Google, Anthropic, OpenAI, …). Pin with Space or /model, or keep Auto.

Models →

Memory

Central and per-project context with approval before anything is saved.

Memory →

CLI, VS Code, MCP

CLI first. Chat extension and sandboxed agent tools in Cursor / VS Code when you need them.

IDE →

From intent to result

You do not need agent names or skill ids — Flow reads your goal.

Intent → Analysis → Agent → Skill → Workflow → Result

Same Flow offline with local GGUF, or on Rodium / Foundry after akomagni connect.

Local, cloud, or hybrid

English CLI by default — akomagni config language fr when you want French.

Private when local

Hugging Face GGUF on your machine. Nothing leaves unless you choose a cloud provider.

Cloud when you need it

One Rodium key for multi-provider catalogue models, or Microsoft Foundry, beside local serve.

Open source

Study, fork, and extend skills, agents, models, and integrations with the community.
