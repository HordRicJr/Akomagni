Quick install

Terminal 
curl -fsSL https://hordricjr.github.io/Akomagni/install/linux | bash
PowerShell 
irm https://hordricjr.github.io/Akomagni/install/windows | iex

Then: akomagni connect · akomagni skill link · akomagni run cli --project ./app

Skills give the model a way to work

A Skill is a specialized method the AI can use for a precise task: development, design, research, writing, product, or business. The model supplies intelligence; Skills supply structure. Link them once with akomagni skill link.
