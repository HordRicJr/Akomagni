Akomagni IDE

Use Akomagni agent tools in Cursor or VS Code today via MCP. Native Code-OSS fork with chat sidebar — planned v1.0.

Today: Cursor / VS Code + MCP

  • Step 1 — Install Akomagni CLI (install guide)
  • Step 2 — Agent pack: pip install "akomagni[agent]"
  • Step 3 — Generate MCP config in your project
  • Step 4 — Restart Cursor/VS Code and enable the Akomagni MCP server

One-command setup

Run inside your project root — writes .cursor/mcp.json and .vscode/mcp.json.

Generate MCP config 
pip install "akomagni[agent]"
akomagni ide setup
akomagni ide status

Approval queue

akomagni mcp pending · akomagni mcp approve <id>
