Akomagni IDE

Use Akomagni agent tools in Cursor or VS Code today via MCP. Native Code-OSS fork with chat sidebar — planned v1.0.

Today: Cursor / VS Code + MCP

  • Step 1 — Install Akomagni CLI (install guide)
  • Step 2 — Agent pack: akomagni config extras agent
  • Step 3 — Generate MCP config in your project
  • Step 4 — Restart Cursor/VS Code and enable the Akomagni MCP server

Connect in one command

Interactive setup — prompts for your API key. Syncs VS Code settings automatically.

akomagni connect 
# Rodium AI (default URL)
akomagni connect rodium

# Azure Foundry
akomagni connect foundry https://YOUR-RESOURCE.openai.azure.com/openai/v1/

# Open VS Code chat UI
akomagni ide open

VS Code extension — Akomagni Chat

Search Akomagni Chat in the VS Code Marketplace (HordRicJr.akomagni-chat). Graphical chat sidebar after akomagni connect.

Online inference (Rodium AI)

Rodium AI is OpenAI-compatible at https://api.rodiumai.io/v1. Docs

Rodium + Akomagni CLI 
$env:RODIUMAI_API_KEY="rd_sk_..."
akomagni config provider rodium
akomagni ide setup --provider rodium
akomagni inference status
akomagni run cli

Azure AI Foundry + VS Code

Install Microsoft Foundry Toolkit for chat in VS Code. Learn docs

Azure Foundry workflow 
# VS Code extension: ms-windows-ai-studio.windows-ai-studio
$env:AZURE_OPENAI_API_KEY="..."
akomagni config provider azure --base-url https://YOUR-RESOURCE.openai.azure.com/openai/v1/
akomagni ide setup --provider azure
akomagni inference status

One-command setup

Run inside your project root — writes MCP config, extensions.json, .env.example, and AKOMAGNI_IDE.md.

Generate MCP config 
akomagni config extras agent
akomagni ide setup
akomagni ide status

Windows (PowerShell)

Full IDE workflow on Windows 
irm https://hordricjr.github.io/Akomagni/install/windows | iex
# Restart PowerShell, then in your project:
akomagni config extras agent
akomagni ide setup
akomagni config provider local
akomagni serve --model qwen2.5-coder-7b
