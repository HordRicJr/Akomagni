Memory

Central and project memory with approval-based capture.

Capabilities

  • Project memory — .akomagni/memory/ per repository
  • Central memory — ~/.akomagni/memory/ across projects
  • Promote — lift project learnings into central memory
  • Auto-capture — queue exchanges for approval before saving
Quick start
akomagni memory status
akomagni memory add "Always use pytest fixtures" --title "Testing"
akomagni memory promote
akomagni memory pending
akomagni memory approve <capture-id>
