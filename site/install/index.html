Get up and running

One command installs Akomagni and the BMAD skill kernel (~110 skills). Then connect a provider and run. Python 3.11+, git, 8 GB RAM.

Install 
curl -fsSL https://hordricjr.github.io/Akomagni/install/linux | bash
Next 
akomagni connect
akomagni run cli --project ./my-app
Use PowerShell (not CMD). No admin required.
Prerequisites (if needed) 
winget install Python.Python.3.12
winget install Git.Git
Install 
irm https://hordricjr.github.io/Akomagni/install/windows | iex

Restart PowerShell, then:

Next 
akomagni connect
akomagni run cli --project ./my-app
  • Install dir: %LOCALAPPDATA%\akomagni
  • Binary: %USERPROFILE%\.local\bin\akomagni.exe
  • Config: %USERPROFILE%\.akomagni\config.yaml
Clone 
git clone https://github.com/HordRicJr/Akomagni.git
cd Akomagni
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
akomagni connect
akomagni run cli --project ./my-app

Install

Run the one-liner for your OS.

Connect

akomagni connect — local, Rodium, or Foundry, then Auto or pinned model.

Run

akomagni run cli --project ./app — BMAD skills answer in the terminal. Sessions stay inside that folder (even if a parent BMAD tree exists).

BMAD kernel (v0.3)

Skills ship with install. No path setup. In the CLI they stay in chat — no IDE handoff. akomagni update refreshes the kernel; akomagni skill list verifies what is installed.

CLI + skills 
akomagni run cli --project ./my-app
# try: help me brainstorm a budget app
akomagni skill list
akomagni doctor

Optional: local models

Only if you want offline GGUF inference.

Local serve 
akomagni config extras inference
akomagni model pull qwen2.5-coder-7b
akomagni serve --model qwen2.5-coder-7b

Language

CLI is English by default.

French UI 
akomagni config language fr

Update

Pulls the latest release, refreshes the BMAD kernel, and prints version + changelog highlights.

Update 
akomagni update

Troubleshooting

  • Command not found — restart the terminal; check PATH includes ~/.local/bin.
  • Windows execution policy — Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  • No skills — run akomagni update (kernel ships with install); optional akomagni skill link for a custom folder
  • Image / poster — cloud uses URL-first image models; base64 is saved under generated-images/
  • Rodium 403/404 — update, reconnect; catalogue ids only (not rodium/basic)
