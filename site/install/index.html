Install Akomagni

One command, then akomagni connect. Local GGUF, Rodium AI, or Microsoft Foundry. Python 3.11+, git, and 8 GB RAM minimum.

One-liner install 
curl -fsSL https://hordricjr.github.io/Akomagni/install/linux | bash
  • ✦ Python 3.11+ and git in PATH
  • ✦ Installs to ~/.local/share/akomagni
  • ✦ Adds ~/.local/bin to your shell profile
  • ✦ Runs smoke test (akomagni --version, doctor)
After install 
akomagni connect
akomagni skill link
akomagni run cli --project ./my-app
Windows 10/11 — open PowerShell (not CMD). No admin required.

Step 1 — Prerequisites

Install Python 3.11+ and Git if missing. Check with python --version and git --version.

winget (recommended) 
winget install Python.Python.3.12
winget install Git.Git

Or download from python.org — check Add python.exe to PATH during setup.

Step 2 — Install Akomagni

PowerShell one-liner 
irm https://hordricjr.github.io/Akomagni/install/windows | iex

If blocked by execution policy, run once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Step 3 — Restart terminal

Close and reopen PowerShell so PATH picks up %USERPROFILE%\.local\bin.

Step 4 — Verify & connect

Smoke test + provider 
akomagni --version
akomagni config init
akomagni doctor
akomagni connect
  • ✦ Installs to %LOCALAPPDATA%\akomagni
  • ✦ Binary at %USERPROFILE%\.local\bin\akomagni.exe
  • ✦ Config at %USERPROFILE%\.akomagni\config.yaml
  • ✦ Virtualenv at %LOCALAPPDATA%\akomagni\.venv

Clone & editable install 
git clone https://github.com/HordRicJr/Akomagni.git
cd Akomagni
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
akomagni config init
akomagni doctor
akomagni connect
akomagni skill link

Environment variables

  • AKOMAGNI_REPO — git URL (default: github.com/HordRicJr/Akomagni)
  • AKOMAGNI_BRANCH — release branch (default: main)
  • AKOMAGNI_INSTALL_DIR — install location
  • AKOMAGNI_BIN_DIR — binary directory for PATH
  • AKOMAGNI_SOURCE_DIR — copy from local path instead of git clone

Update Akomagni

Pull the latest release and reinstall the CLI (keeps your config and models). After update, run akomagni connect again if you use Rodium so the model map refreshes.

Update command 
akomagni update
akomagni connect

Or re-run the install one-liner — it also updates an existing install.

Troubleshooting

  • pip: No matching distribution (platformdirs…) — check internet access to pypi.org. Or install manually: python -m pip install platformdirs typer rich pyyaml psutil sqlite-vec then pip install -e . --no-deps in %LOCALAPPDATA%\akomagni.
  • Python 3.14+ — Python 3.12 is recommended: winget install Python.Python.3.12
  • Command not found after install — restart PowerShell/terminal. On Windows, check %USERPROFILE%\.local\bin is in your user PATH.
  • Execution policy blocked (Windows) — Set-ExecutionPolicy -Scope CurrentUser RemoteSigned then retry the install command.
  • git not found (Windows) — winget install Git.Git and restart terminal.
  • Inference offline — for local: akomagni serve --model <name> after a pull. For cloud: akomagni connect and pick Rodium or Foundry.
  • No skills found — run akomagni skill link (or pass a skills folder). On PowerShell: akomagni skill list | Select-String bmad-.
  • Rodium chat 404 — update, then akomagni connect. Akomagni uses provider-scoped catalogue ids, not empty profiles like rodium/basic.
