Code & Flow

Describe the goal. Flow picks the agent and skill. Build with CLI, RAG context, and sandboxed MCP tools.

Capabilities

  • Akomagni Flow — Intent → Analysis → Agent → Skill → Workflow → Result across 17 BMAD agents
  • Skills — akomagni skill link, skill list, discover from ~/.akomagni/skills and project trees
  • Sessions — flow invoke / interactive CLI writes BMAD activation session files
  • MCP tools — sandboxed fs, shell, and git with an approval queue
  • RAG — hybrid BM25 + vector ingest injected into prompts
  • Greenfield — English intents like “build a…” route to brainstorming first
Quick start
akomagni skill link
akomagni run cli --project ./my-app
akomagni flow route "Add JWT auth to the API"
akomagni flow invoke "Add JWT auth to the API"
akomagni skill list
akomagni rag ingest docs/ --recursive
akomagni mcp serve
