Models

Local GGUF offline, or multi-provider cloud via Rodium / Foundry. Auto Router picks by task — or pin a strong model yourself.

Local (Hugging Face GGUF)

  • akomagni model pull phi-3.5-mini or any owner/repo:file.gguf
  • akomagni serve --model … — OpenAI-compatible API on 127.0.0.1:8787
  • akomagni doctor / model recommend for hardware-aware picks
  • Optional Hub token via akomagni connect for gated repos

Rodium cloud (multi-provider)

  • One API key → Google, Anthropic, OpenAI, DeepSeek, rodiumai/smart, and more
  • Auto routes by domain (code, design, image, chat) using live catalogue pricing when available
  • Pin Claude Sonnet, Gemini Pro, GPT-5.4, DeepSeek Pro, image models… during connect or in CLI with Space / /model
  • Images: quality-first (Gemini Pro/Flash Image, gpt-image). CLI asks where to save the PNG
  • Legacy rodium/basic|fast|pro ids remap to current catalogue models
Quick start
akomagni connect
akomagni doctor
akomagni model pull qwen2.5-coder-7b
akomagni serve --model qwen2.5-coder-7b
akomagni run cli --project ./my-app
# In CLI: press Space or type /model to change the Rodium model
