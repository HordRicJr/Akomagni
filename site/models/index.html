Models

Local GGUF inference with OpenAI-compatible API.

Capabilities

  • akomagni serve — llama-server on 127.0.0.1:8787
  • akomagni model pull — download models from Hugging Face
  • Domain router swaps models for code, design, image, and text
  • Hardware-aware recommendations via akomagni doctor
Quick start
akomagni doctor
akomagni model recommend
akomagni model pull Qwen2.5-Coder-7B
akomagni serve --model qwen2.5-coder-7b
akomagni inference chat "Explain this function"
