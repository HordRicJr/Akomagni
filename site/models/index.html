Models

Local GGUF offline, or Rodium / Foundry in the cloud. Auto Router picks the right tier for the task.

Local (Hugging Face GGUF)

  • akomagni model pull phi-3.5-mini or owner/repo:file.gguf
  • akomagni serve --model phi-3.5-mini on 127.0.0.1:8787
  • Optional Hub token via akomagni connect for gated models

Rodium (token-aware routing)

  • Text / brainstorm → cheapest chat (often google/gemini-*-flash-lite)
  • Code → rodiumai/smart (Rodium picks a strong coding model)
  • Design / creative → mid-tier (e.g. anthropic/claude-haiku-*)
  • Image / poster → image models (google/gemini-*-flash-image, Imagen, gpt-image)
  • Any catalogue id works: Google, Anthropic, OpenAI, DeepSeek, … via one API key
  • Live pricing from GET /v1/models prefers lower RODI when online
  • Connect with akomagni connect, then akomagni run cli
Quick start
akomagni connect
akomagni doctor
akomagni model pull phi-3.5-mini
akomagni serve --model phi-3.5-mini
akomagni run cli --project ./my-app
