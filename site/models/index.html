Models

Three inference paths that stay separate: local GGUF, Rodium catalogue, or Foundry deployments. Hugging Face is for download (catalog name, owner/repo, or a model link) — not a cloud chat backend.

Local

Offline llama-server. Pull a GGUF, then serve.

akomagni connect local

Rodium

One key, catalogue ids (google/…). Images stay on Rodium.

akomagni connect rodium

Foundry

Azure deployment names only. Key: --auth api_key.

akomagni connect foundry <url>

Hugging Face

Hub token for pulls. Not an inference provider.

akomagni connect hf

Any Hugging Face link

Larger models (Qwen3 Coder, etc.) stay optional — paste the Hub URL or owner/repo:file.gguf. Gated repos need akomagni connect hf first.

Pull from a link
akomagni connect hf
akomagni model pull https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct-GGUF
akomagni model pull owner/repo:file.gguf
akomagni model catalog
akomagni serve --model qwen2.5-coder-7b

Cloud commands

  • Rodium — akomagni connect rodium then Space / /model in the CLI
  • Foundry — akomagni connect foundry https://RESOURCE.openai.azure.com/openai/v1/ --auth api_key
  • Images on Foundry need an image deployment (gpt-image-1 / dall-e-3). Catalogue image models stay on Rodium.
